# הפרויקטים של ים

אתר תיק עבודות סטטי בעברית ובאנגלית: HTML ו-CSS, בלי framework.
קובץ JavaScript קטן (`templates/site.js`, נטען עם `defer`) רק מוסיף אפקטים: עוצר את תנועת הזוהר כשהכותרת לא על המסך,
הזוהר שעוקב אחרי העכבר על הכרטיסים, סימון הקטגוריה שעל המסך, דהייה בקצה של סרגל הקטגוריות ווידאו הרקע. בלעדיו הכול מוצג ועובד.

```
python tools/build.py
```

הפקודה בונה את `public/` מחדש מ-`projects.json`, `templates/`, `images/`, `fonts/` ו-`videos/`:
העמוד העברי ב-`public/index.html` (ברירת המחדל, `/`) והאנגלי ב-`public/en/index.html` (`/en/`), מאותן תבניות.
כל מה שב-`public/` נוצר אוטומטית ונמחק בכל בנייה, אז עורכים רק את המקורות.

## להוסיף, לשנות או להוריד פרויקט

הכול ב-[projects.json](projects.json). כל פרויקט הוא רשומה אחת:

| שדה | מה זה |
|---|---|
| `slug` | מזהה באנגלית, משמש לשם הקובץ ולעוגן (`#slug`) |
| `name`, `subtitle` | השם, ושם משני אופציונלי |
| `kicker` | מה זה, מעל השם (למשל «אפליקציה לאנדרואיד») |
| `category` | אחד מה-`id` שב-`categories` |
| `status` | אחד מהמפתחות שב-`statuses` (שוחרר, בפיתוח וכו') |
| `version` | אופציונלי, מוצג ליד הסטטוס |
| `summary` | משפט אחד |
| `highlights` | נקודות: שתי הראשונות מוצגות תמיד, השאר נפתחות ב«עוד פרטים» |
| `tech` | תגיות טכנולוגיה |
| `device` | מסכים אמיתיים בתוך מסגרת: `{ "type": "phone" או "window", "screens": ["..."], "alt": "..." }`. המסך הראשון מלפנים; בכרטיס מוגדל מוצגים עד שלושה טלפונים. הטלפון והחלון הראשונים מופיעים גם ליד הכותרת הראשית ובתמונת השיתוף |
| `image`, `alt` | תמונה מתוך `images/` (צילום מסך או תמונת משחק), נחתכת ל-16:10 מהמרכז ומוצגת במסגרת זכוכית. כשיש גם `device` היא לא מוצגת בכרטיס |
| `crop: "top"` / `fit: "contain"` | לחתוך מלמעלה / להציג את כל התמונה (ללוגו) |
| `art` | כשאין תמונה: כריכה מצוירת (`rings`, `wave3d`, `voice`, `agents`, `timing`, `waveform`, `hex`, `chip`, `letters`) |
| `flag` | דגל קטן בפינה של התמונה (כרגע רק `"il"`, «תרגום ישראלי») |
| `icon`, `glyph` | אייקון מתוך `images/` (PNG או SVG); בלי אייקון מוצגת האות `glyph` על אריח צבעוני |
| `accent`, `accent2` | צבעי הכרטיס והכריכה, וגם של הזוהר ברקע. צבע הטקסט על הכפתור (כהה או לבן) נבחר לפי ניגודיות |
| `links` | כפתורים: `{ "label": "...", "url": "..." }`, ואפשר `"hreflang": "he"` לאתר שכולו בעברית |
| `en` | הגרסה האנגלית של השדות שלמעלה (`name`, `subtitle`, `kicker`, `summary`, `highlights`, `alt`, `image`, `device`, `links`). מה שחסר בו נלקח מהעברית |

גם לשאר הטקסטים יש גרסה אנגלית: `owner.en`, `en` בכל קטגוריה ו-`statuses_en`.
הטקסטים של העמוד עצמו (כפתורים, תוויות, כותרת תחתונה, עמוד 404) נמצאים ב-`ui`, תחת `he` ו-`en`.
הפרויקט הראשון בכל קטגוריה מוצג מוגדל לכל רוחב השורה, ואחריו כרטיסים בשתי עמודות.

כדי להוריד פרויקט מוחקים את הרשומה שלו (ואת התמונה שלו מ-`images/`, אם יש) ובונים מחדש.

קישורים באתר מובילים רק לאתרים של הפרויקטים עצמם, אף פעם לא למאגרי הקוד ב-GitLab או ב-GitHub.
מותרים גם עמוד ה-Ko-fi (`ko-fi.com`) של כפתור התמיכה, ודף מדיניות הפרסום של Google כשהפרסומות פועלות.

## הפרטים של האתר (`owner`)

- `donate`: כפתור תמיכה (Ko-fi) בכותרת הראשית ובתחתית העמוד. כל עוד `url` ריק לא מוצג כלום.
  כשיש עמוד Ko-fi ממלאים את הכתובת שלו, למשל `"url": "https://ko-fi.com/<שם>"`. התוויות ב-`label` וב-`en.label`.
- `ads`: פרסומות של Google AdSense. כל עוד `client` ריק אין באתר שום סקריפט, אין `ads.txt` ואין מקום שמור.
  כשיש מזהה מפרסם ממלאים את `client` (`ca-pub-` ו-16 ספרות). אז נוספים הסקריפט, הקובץ `public/ads.txt`,
  ושורת הפרטיות בתחתית העמוד, והמשפט «בלי עוגיות ובלי מעקב» מתחלף. ב-`slots` אפשר לשים מזהי יחידות:
  `between` (בין הקטגוריות) ו-`footer` (לפני התחתית). בלי מזהים פועלות רק המודעות האוטומטיות.
  חשוב לדעת: AdSense צריך לאשר את האתר, וכנראה ידרוש דומיין משלו (לא `github.io`).
  למבקרים מאירופה ומבריטניה מפעילים ב-AdSense את הודעת ההסכמה של Google: Privacy & messaging.

## וידאו הרקע

ב-`videos/` יש לולאות של 12 שניות שמתחברות בלי קפיצה, אחת לכל ערכת צבעים: `bg-dark` ו-`bg-light`,
כל אחת ב-WebM ו-MP4 ב-1920×1080, ובגרסת `-720` ב-960×540 לטלפונים, ועם תמונת פתיחה (`.webp`).
הבנייה מעתיקה אותן ל-`public/video/`. תמונת הפתיחה מוצגת תמיד. את הווידאו טוען `site.js` רק אחרי שהעמוד
מוצג, ורק כשאין בקשה להפחתת תנועה ואין Save-Data. הוא מתנגן רק כשהכותרת הראשית על המסך והלשונית גלויה. כפתור «עצירת תנועה» בסרגל העליון עוצר אותו ואת כל האנימציות, והבחירה נשמרת במכשיר.
כדי להחליף את הסרטונים שמים קבצים חדשים באותם שמות.

## טיוטות

ב-`drafts/` שמורים פרויקטים שכרגע לא מופיעים באתר: הרשומות שלהם ב-[drafts/projects.json](drafts/projects.json) והתמונות ב-`drafts/images/`.
כדי להחזיר פרויקט, מעבירים את הרשומה שלו ל-`projects.json` ואת התמונה ל-`images/`, ובונים מחדש.
התיקייה הזאת לא נכנסת למאגר הציבורי (היא ב-`.gitignore`).

## תצוגה מקדימה

```
python -m http.server 8766 --directory public
```

ואז לפתוח <http://localhost:8766> (והאנגלית ב-<http://localhost:8766/en/>).

## תמונות התצוגה המקדימה

התמונות שמופיעות כשמשתפים קישור לאתר (וואטסאפ, טוויטר וכו') הן `images/og.jpg` (עברית) ו-`images/og-en.jpg` (אנגלית), בגודל 1200×630.
כל עמוד מפנה לתמונה שלו. אחרי שינוי בפרויקטים או בכותרת מייצרים את שתיהן מחדש:

```
python tools/og.py
```

הסקריפט משתמש ב-Chrome או ב-Edge במצב headless, כי Pillow לא יודע לסדר כאן טקסט בעברית.
העיצוב שלהן נמצא ב-`templates/og.html`.

## פרסום

GitHub Pages, באותה דרך כמו `hinachti-site`: ה-Action שב-[.github/workflows/pages.yml](.github/workflows/pages.yml)
מעלה את `public/` בכל push ל-`main`. שום דבר לא נבנה בשרת, ולכן את `public/` מקמטים כמו שהוא.

כשבוחרים את שם החשבון:

1. ב-GitHub יוצרים מאגר **ציבורי** וריק בשם `<שם>.github.io`, בלי README.
2. ב-[projects.json](projects.json) ממלאים את `site_url` ב-`https://<שם>.github.io/` ומריצים את `python tools/build.py`.
   בלי הכתובת הזאת אין באתר תמונות שיתוף, קישורי canonical ו-hreflang ו-sitemap, כי הם צריכים כתובת מלאה.
3. מחליפים את זהות ה-commit במאגר הזה לכתובת noreply של האתר, ומעדכנים את ה-commit הראשון.
4. מחברים את המאגר (`git remote add origin ...`) ודוחפים את `main`.
5. ב-GitHub: Settings ← Pages ← Source: **GitHub Actions**.
